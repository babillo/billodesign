# Project Overview

Timms Team wanted a dedicated conversion page to attract more qualified renovation leads in Germany. While the main website existed, they needed a high-impact, focused landing page that communicated trust, showcased expertise, and drove visitors toward booking a consultation.

My role was to transform a basic page idea into a complete conversion-centered experience—using UX strategy, clear messaging, and Webflow implementation to support their lead-generation goals.

<Spacer />

# The Solution

I designed a fully optimized landing page built around psychological conversion triggers and industry trust signals. Key elements included:

- **Premium hero section** with clear value proposition
- **Trust badges & credibility markers** placed above the fold
- **Service breakdown with clear benefits**
- **Transformation showcase** with before/after visuals
- **Social proof section** including reviews & client logos
- **Strong call-to-actions** placed strategically across the page
- **Mobile-first responsive layout** optimized for 80% mobile users
- **High-speed, SEO-friendly Webflow build**
- **A conversion-oriented form with lead-qualifying fields**

The design approach focused strongly on clarity, trust, and real-world proof — the elements that matter most in home-improvement and renovation industries.

<Spacer />

# The Result

The new landing page significantly improved Timms Team’s online presence and lead-generation quality. The client described the result as “Amazing work again,” reinforcing strong ongoing collaboration.

The landing page now:

- Communicates value clearly and professionally
- Establishes high credibility within seconds
- Guides users smoothly toward taking action
- Supports the company’s sales funnel more effectively
- Strengthened the business–designer relationship, leading to more projects
