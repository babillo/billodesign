# Project Overview

Designed and developed a high-performance, interactive portfolio website for a System Administrator specializing in enterprise IT infrastructure, hybrid environments, and virtualization.

# The Challenge/Problem

Fadi needed a modern, premium website that:

- Positions him as a serious Enterprise IT Professional
- Showcases hands-on Home Lab projects
- Demonstrates real-world enterprise experience
- Feels advanced — but not over-designed
- Is fully manageable by him after delivery

**Challenges:**

- Complex CMS structure (Labs + Categories + Templates)
- Advanced animations without harming performance
- High design precision expectations
- Multiple structural refinements during final review
- Maintaining visual balance across 2K screens

# Strategy {hidden}

### My Approach

#### 🧩 Phase 1 — Design System & Direction

- Created a futuristic yet professional visual identity
- Built a modular design system (typography, glow accents, card structure)
- Balanced sci-fi aesthetic with enterprise credibility
- Designed scalable layout for CMS-driven expansion

#### ⚙️ Phase 2 — Webflow Implementation

##### CMS Architecture

- Multi-reference category system
- Lab filtering logic
- Dynamic category template pages
- Featured + paginated layout structure
- Responsive flexible card system (bento behavior)

##### Animation System

- Webflow native interactions
- Custom GSAP scroll-trigger animations
- Text-split stagger effects
- Scroll-based highlight animations
- Performance-conscious animation design

##### Performance Optimization

- Image compression
- SEO structure
- Alt text strategy
- Lighthouse optimization
- Removed unnecessary external scripts
